## 12. 页面与前端规范

1. 使用 Bootstrap 统一后台风格。
2. 统一顶部栏、左侧菜单、面包屑、内容区、页脚。
3. CSS 和 JS 从 bootcdn 引入。
4. 菜单、表格、表单数据全部通过 API 获取。
5. 页面不得写入测试数据；空状态由 API 返回空数组后渲染。
6. 表格支持查询、分页、排序、导出权限控制。
7. 表单统一校验必填、长度、格式、权限。
8. 文件上传统一使用后端附件 API。
