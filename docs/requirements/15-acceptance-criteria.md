# 涉密含党支部企业管理系统需求文档

> 本文件由根目录 `需求文档.md` 拆分而来，便于 GitHub 直接预览。完整总览请查看 `../../REQUIREMENTS.md`。

## 15. 验收标准

1. admin 登录后可看到全部菜单。
2. dpt1 登录后仅看到被授权菜单。
3. user1 登录后仅看到普通用户或被授权菜单。
4. 前端菜单由 `/api/menus/tree.php` 返回结果动态渲染。
5. 无权限用户直接访问 API 时返回 403。
6. 注册、登录、找回密码均需要验证码。
7. 所有页面数据来自 `/api`，页面中无静态测试数据。
8. 系统管理员可维护模块、菜单、角色和权限。
9. 待办、通知等至少支持 AJAX 局部刷新。
10. 登录日志、操作日志可查询。
11. README 项目结构与实际文件保持一致。
12. 审批中心可以展示各业务模块审批任务，但不复制业务单据明细。
13. 项目报销能关联项目并在入账后汇总到项目成本。
14. 合同能关联客户、项目、财务收付款和审批记录。
15. 物料申请能关联项目、工程或运维工单，并形成库存流水。
16. 党建党员信息能关联员工档案，党建学习能关联培训记录。
17. 工作台待办、消息和快捷入口均通过 API 聚合并按权限过滤。
18. 党建管理具备党组织、党员、发展党员、三会一课、主题党日、党费、党建学习、党建台账完整功能。
19. 党建资料能关联通知公告、培训记录、附件和涉密管理。
20. 涉密管理具备密级规则、涉密对象、涉密文件、涉密载体、定密审批、借阅外发、保密检查、泄密事件、涉密审计完整功能。
21. 涉密对象访问时能同时校验菜单/API 权限、数据范围、密级授权和知悉范围。
22. 涉密下载、导出、外发、复制、打印等高风险操作能单独审批或记录审计。
23. 协作团队管理具备团队档案、内部人员、外部人员、外聘人员、外部公司、资质、派工、执行记录、评价、结算完整功能。
24. 项目、工程、运维、市场任务能引用协作团队，并能回写执行记录和评价结果。
25. 供应链采购管理支持供应商申请入驻、注册后审批、后台添加和供应商后台。
26. 供应商可上传商品，并参与平台发起的询价和竞价。
27. 供应商可对部分商品或全部商品报价，平台能汇总报价并生成最优比价清单。
28. 最优比价清单可包含多家供应商和多种商品，并能一键下单。
29. 一键下单后必须进入审批，审批通过后才向各供应商发送采购通知。
30. 供应商供货后的到货、入库、签收能回写库存，付款能关联财务管理。
31. 客户管理能按摧龙六式记录客户分析、建立信任、挖掘需求、呈现价值、赢取承诺、回收账款全过程。
32. 客户联系人画像能记录职务、影响力、联系方式、喜好、家庭情况、社会关系和合规备注，并按权限查看。
33. 客户拜访、商务活动、商机、合同、回款、服务记录能形成客户交接包。
34. 客户负责人离职或调岗时，接任人能通过客户交接包快速掌握客户全貌、关键关系、历史沟通、风险和下一步动作。
35. 运维管理具备设备台账、计划、巡检、工单、派工、SLA、备件、知识库、安全事件和报表闭环。
36. 工程管理具备工程创建、施工计划、过程跟踪、施工日志、材料设备、质量安全、变更签证、验收交付和报表闭环。
