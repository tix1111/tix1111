# 涉密含党支部企业管理系统需求文档

> 本文件由根目录 `需求文档.md` 拆分而来，便于 GitHub 直接预览。完整总览请查看 `../../REQUIREMENTS.md`。

## 6. 总体菜单结构

系统采用二级菜单为主，后续可在子页面内部扩展三级页签或列表操作。

### 6.1 工作台

| 二级菜单 | 功能说明 |
| --- | --- |
| 首页仪表盘 | 展示待办、通知、业务数据概览、快捷入口 |
| 待办中心 | 审批待办、工单待办、培训待办、项目待办 |
| 通知中心 | 企业通知、公告、党建通知、系统消息 |
| 常用功能 | 打卡、立项、拜访、报销、工单、工程、零散、物料、培训 |
| 个人日程 | 日程提醒、会议提醒、任务安排 |
| 数据看板 | 按角色展示项目、财务、人事、库存、运维指标 |

### 6.2 审批管理

| 二级菜单 | 功能说明 |
| --- | --- |
| 审批中心 | 我发起的、待我审批的、我已审批的、抄送我的，支持按业务类型筛选 |
| 流程配置 | 审批流程设置、节点配置、条件分支、审批人规则 |
| 表单配置 | 表单字段、表单权限、表单版本、业务类型绑定 |
| 审批委托 | 委托审批、委托记录、代理人设置、委托有效期 |
| 审批报表 | 审批效率、超时统计、驳回统计、节点瓶颈分析 |
| 审批日志 | 审批流转日志、意见记录、撤回/转交/加签记录 |

### 6.3 项目管理

| 二级菜单 | 功能说明 |
| --- | --- |
| 项目立项 | 新建项目、项目列表、立项审批 |
| 项目计划 | 任务分解、进度计划、里程碑 |
| 项目执行 | 任务分配、进度跟踪、问题反馈 |
| 项目资源 | 人员、设备、材料分配 |
| 项目成本 | 成本预算、实际成本、成本分析 |
| 项目文档 | 方案、图纸、验收资料、过程文件 |
| 项目报告 | 项目状态报告、周报、月报、风险报告 |
| 项目变更 | 范围变更、费用变更、延期申请 |

### 6.4 客户管理

| --- | --- |
| 客户档案 | 企业基础信息、经营情况、组织结构、历史合作、客户画像 |

| 商机管理 | 商机列表、机会来源、需求痛点、竞争情况、阶段管理 |
| 客户合同关联 | 客户相关合同摘要、履约状态、回款概览，合同正文归属合同管理 |
| 客户交接 | 负责人变更、交接清单、关键关系、风险事项、接任建议 |

### 6.18 去重后的菜单栏目细化

本节用于约束每个二级菜单的页面栏目和业务归属。表中的“核心栏目/字段”是开发列表页、详情页和表单时应优先保留的内容；“说明”用于标明数据来源和是否仅为引用视图。

#### 6.18.1 工作台栏目

| 二级菜单 | 核心栏目/字段 | 说明 |
| --- | --- | --- |
| 首页仪表盘 | 待办数量、未读通知、项目概览、审批概览、库存预警、涉密提醒 | 只做汇总展示，数据来自各业务 API |
| 待办中心 | 待办类型、标题、来源模块、发起人、到达时间、超时时间、状态 | 聚合审批、工单、培训、保密检查、党建活动待办 |
| 通知中心 | 消息类型、标题、发布人、发布时间、阅读状态、反馈状态 | 展示系统消息和通知公告，不创建业务公告 |
| 常用功能 | 功能名称、所属模块、权限状态、最近使用时间 | 快捷入口，不保存业务数据 |
| 个人日程 | 日程标题、类型、开始时间、结束时间、关联业务、提醒状态 | 可关联会议、拜访、培训、党建活动 |
| 数据看板 | 指标名称、统计周期、数据范围、趋势、预警状态 | 按角色和数据权限展示 |

#### 6.18.2 审批管理栏目

| 二级菜单 | 核心栏目/字段 | 说明 |
| --- | --- | --- |
| 审批中心 | 业务类型、单据编号、标题、发起人、当前节点、到达时间、审批状态 | 只展示审批任务，业务详情跳转原模块 |
| 流程配置 | 流程名称、适用业务、节点名称、审批人规则、条件分支、启停状态 | 系统管理员或授权管理员维护 |
| 表单配置 | 表单名称、业务类型、字段名称、字段权限、版本号、启用状态 | 表单配置服务于业务单据，不替代业务表 |
| 审批委托 | 委托人、代理人、委托范围、开始时间、结束时间、状态 | 仅影响审批任务处理人 |
| 审批报表 | 业务类型、平均耗时、超时数量、驳回率、节点耗时 | 统计审批效率，不统计业务经营结果 |
| 审批日志 | 单据编号、节点、处理人、动作、意见、处理时间 | 不允许普通用户删除 |

#### 6.18.3 项目管理栏目

| 二级菜单 | 核心栏目/字段 | 说明 |
| --- | --- | --- |
| 项目立项 | 项目编号、项目名称、客户、负责人、预算、立项状态、密级 | 项目主数据入口 |
| 项目计划 | 任务名称、里程碑、计划开始/结束、责任人、前置任务 | 形成项目执行基线 |
| 项目执行 | 任务状态、进度、问题、风险、反馈人、更新时间 | 不直接处理工程施工明细 |

| 质量评价 | 评价对象、质量分、时效分、安全分、反馈、整改 | 影响后续派工和结算 |
| 结算管理 | 结算对象、来源任务、工时/工程量、金额、审批状态、付款状态 | 付款进入财务管理，应付对象可关联合同 |

#### 6.18.17 供应链采购管理栏目

| 二级菜单 | 核心栏目/字段 | 说明 |
| --- | --- | --- |
| 供应商入驻 | 申请来源、注册账号、企业信息、资质、审批状态 | 支持自主申请、注册后审批、后台添加 |
| 供应商档案 | 供应商编号、名称、联系人、经营范围、等级、状态 | 供应商主数据入口 |
| 供应商后台 | 商品维护、报价入口、订单通知、发货反馈、资料维护 | 面向供应商账号的后台能力 |
| 商品目录 | 商品编码、名称、规格参数、单位、价格、库存、上下架 | 供平台查询、询价、采购 |
| 询价管理 | 项目/工程/工单、物料清单、参数、供应商范围、截止时间 | 平台发起，供应商报价 |
| 竞价管理 | 竞价批次、参与供应商、报价轮次、最低价、排名 | 支持部分商品报价和全部商品报价 |
| 报价管理 | 供应商、商品、报价、税率、运费、交期、有效期 | 报价是供应商维度数据 |
| 比价清单 | 商品、最低报价、推荐供应商、替代报价、比价规则 | 可生成多供应商组合的最优采购清单 |
| 采购下单 | 采购单、供应商拆单、审批状态、供货期限、收货地址 | 一键下单后进入审批，通过后通知供应商 |
| 履约评价 | 准时率、合格率、价格偏差、服务评分、违约记录 | 影响供应商等级和后续准入 |
