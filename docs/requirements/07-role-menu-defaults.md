# 涉密含党支部企业管理系统需求文档

> 本文件由根目录 `需求文档.md` 拆分而来，便于 GitHub 直接预览。完整总览请查看 `../../REQUIREMENTS.md`。

## 7. 角色默认菜单建议

### 7.1 系统管理员

系统管理员默认拥有全部 17 个主菜单和所有二级菜单权限，包括系统管理、协作团队管理、供应链采购管理、涉密管理、党建管理、模块管理、权限管理、数据备份、安全设置等高危操作。

### 7.2 部门管理员

建议默认开放：

1. 工作台
2. 审批管理：审批中心、审批委托、审批报表、审批日志
3. 项目管理：项目立项、项目计划、项目执行、项目资源、项目成本、项目文档、项目报告
4. 客户管理：客户信息、客户分类、客户拜访、商机管理、客户合同关联、客户分析
5. 人事管理：组织架构、员工管理、考勤管理、薪酬管理、绩效管理、员工成长档案、党务关联
6. 财务管理：费用报销、应收管理、应付管理、借款管理、总账管理、财务报表、预算管理、资产管理
7. 运维管理：设备台账、运维计划、工单管理、巡检管理、安全管理
8. 工程管理：工程列表、新建工程、过程跟踪、验收培训
9. 合同管理：合同起草、合同流程、合同执行、合同归档、合同查询、合同分析
10. 库存管理：物料管理、物料采购、入库管理、出库管理、库存调拨、库存盘点、库存查询、库存分析
11. 培训管理：培训资源、培训计划、在线培训、考试管理、培训记录、学习计划、培训统计
12. 通知公告：通知管理、公告管理、意见反馈、消息模板、消息订阅、阅读统计
13. 涉密管理：涉密项目、涉密文件、涉密载体、借阅外发、保密检查、保密教育、涉密审计
14. 党建管理：党组织管理、党员管理、发展党员、三会一课、主题党日、党费管理、民主评议、党建学习、党建公告、党建台账
15. 协作团队管理：团队档案、内部人员、外部人员、外聘人员、外部公司、资质管理、团队派工、执行记录、质量评价、结算管理
16. 供应链采购管理：供应商入驻、供应商档案、商品目录、询价管理、竞价管理、报价管理、比价清单、采购下单、履约评价

部门管理员是否拥有系统管理菜单、协作团队全局维护、供应商准入审批、涉密高危操作和党建全局维护权限，由系统管理员授权决定。默认不开放用户、权限、数据备份、全局密级规则、涉密审计删除、党组织全局调整、供应商全局评级等能力。

### 7.3 普通用户

建议默认开放：

1. 工作台：首页仪表盘、待办中心、通知中心、常用功能、个人日程
2. 审批管理：审批中心
3. 财务管理：费用报销、应付管理、借款管理
4. 人事管理：请假、加班、员工档案、荣誉、打卡记录、培训信息和记录、在线会议
5. 客户管理：客户档案、拜访计划、拜访记录
6. 项目管理：立项申请、进度跟踪反馈、项目文档
7. 运维管理：设备信息、计划执行、工单反馈、安全管理执行情况、特殊事件报告
8. 工程管理：创建工程或零散、过程跟踪、验收培训信息填写
9. 合同管理：合同模板、合同查询、合同执行、合同到期提醒
10. 库存管理：物料申请、物料发货、到货情况、物料签收
11. 培训管理：培训计划、在线培训、考试管理、培训记录、学习计划、课程浏览
12. 通知公告：查看公告、公告反馈
13. 涉密管理：查看本人授权涉密事项、发起借阅申请、归还确认、保密教育、保密承诺书
14. 党建管理：查看本人党员档案、参加三会一课和主题党日、党费缴纳记录、党建学习、党建公告反馈
15. 协作团队管理：查看本人任务派工、填写执行记录、提交现场反馈、查看评价结果
16. 供应链采购管理：商品查询、报价结果查看、采购签收、供应商订单进度查看
17. 个人设置：更改密码、更新个人资料
