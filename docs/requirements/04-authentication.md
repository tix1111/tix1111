## 4. 登录与账号体系

### 4.1 注册

字段：

1. 账号
2. 密码
3. 手机号
4. 验证码

规则：

1. 账号唯一。
2. 手机号唯一或按企业策略限制。
3. 密码需满足复杂度策略。
4. 验证码有效期建议 5 分钟。
5. 注册成功后默认分配普通用户角色，或进入待审核状态由管理员确认。

### 4.2 登录

字段：

1. 账号
2. 密码
3. 验证码

规则：

1. 校验账号状态、密码、验证码。
2. 登录成功后生成服务端会话。
3. 返回用户资料、角色信息、权限摘要和可用菜单。
4. 连续失败达到阈值后锁定账号或触发二次校验。

### 4.3 找回密码

字段：

1. 账号
2. 手机号
3. 验证码
4. 新密码
5. 确认新密码

规则：

1. 账号与手机号必须匹配。
2. 验证码校验通过后允许重置密码。
3. 密码重置后清理旧会话。
4. 记录密码重置日志。

### 4.4 验证码类型

1. 图形验证码：适用于注册、登录、找回密码基础校验。
2. 短信验证码：适用于手机号验证和密码找回。
3. 内网涉密部署时，如不接入公网短信网关，可使用企业内短信平台或管理员线下重置流程。
