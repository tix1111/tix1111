# 涉密含党支部企业管理系统需求文档

> 本文件由根目录 `需求文档.md` 拆分而来，便于 GitHub 直接预览。完整总览请查看 `../../REQUIREMENTS.md`。

## 14. 实施阶段拆解

### 14.1 第一阶段：基础框架与权限

1. 初始化数据库 `lz`。
2. 建立 PHP API 基础结构。
3. 完成登录、注册、找回密码、验证码。
4. 初始化 admin、dpt1、user1。
5. 完成用户、角色、部门、岗位、模块、菜单、权限点、数据范围基础表。
6. 完成统一 API 响应、数据库连接、会话管理、CSRF 校验和操作日志。
7. 完成动态菜单接口和后台布局。
8. 完成附件、待办、消息、业务事件的基础表设计。

### 14.2 第二阶段：系统管理与工作台

1. 用户管理。
2. 角色管理。
3. 模块管理。
4. 菜单管理。
5. 权限管理。
6. 数据字典和系统参数。
7. 工作台仪表盘。
8. 待办、消息、快捷入口 API。
9. 通知和待办局部刷新。

### 14.3 第三阶段：主数据与流程中心

1. 组织架构、员工档案、岗位。
2. 客户档案、联系人、客户分类。
3. 物料档案、仓库、设备台账。
4. 协作团队类型、供应商类型、商品分类、采购类型、资质类型。
5. 合同类型、合同模板、费用类别等字典。
6. 审批流程定义、审批节点、审批任务。
7. 通知公告、附件上传、消息提醒。
8. 统一引用数据 API。

### 14.4 第四阶段：核心业务闭环

1. 客户商机到项目立项闭环。
2. 客户档案、联系人画像、拜访、商务活动、客户交接包。
3. 项目计划、任务、资源、成本、文档。
4. 合同起草、审批、执行、归档。
5. 财务报销、付款、借款、还款、应收应付。
6. 运维计划、巡检、工单、SLA、知识库、安全事件。
7. 工程创建、施工计划、过程跟踪、变更签证、验收交付。
8. 物料申请、采购、入库、出库、签收。
9. 协作团队派工、执行记录、质量评价和结算。
10. 供应链采购询价、竞价、报价、比价清单和采购下单。

### 14.5 第五阶段：协作团队与供应链采购闭环

1. 协作团队档案、内部人员、外部人员、外聘人员、外部公司。
2. 团队资质、准入、派工、执行记录、评价、结算。
3. 供应商入驻、注册后审批、后台添加。
4. 供应商后台、商品目录、商品参数、上下架。
5. 询价、竞价、供应商部分或全部商品报价。
6. 最优比价清单、多供应商组合采购方案、一键下单。
7. 下单审批、供应商通知、发货、到货、入库、签收、履约评价。

### 14.6 第六阶段：党建管理闭环

1. 党组织管理、党员管理、党员发展流程。
2. 三会一课、主题党日、民主评议、党费管理。
3. 党建学习、党建公告、党建台账。
4. 党建与员工档案、培训记录、通知公告、附件、涉密资料联动。
5. 党建统计报表。

### 14.7 第七阶段：涉密管理与安全治理

1. 密级管理、涉密对象、涉密项目、涉密文件、涉密载体。
2. 定密审批、密级变更、解密申请。
3. 借阅外发、归还确认、下载导出审批。
4. 保密检查、整改闭环、泄密事件处置。
5. 涉密审计、异常告警、访问控制、备份审计。
6. 项目、合同、附件、党建台账等业务对象接入涉密控制。

### 14.8 第八阶段：培训、报表与综合治理

1. 培训资源、培训计划、在线考试、证书管理。
2. 项目、财务、库存、合同、运维、人事、协作团队、供应链采购、党建、涉密综合报表。
3. 数据备份、安全设置、访问限制、异常告警。
4. 系统运行监控、日志归档、性能优化。
