## 11. 实时无刷新方案

### 11.1 适用场景

1. 待办数量更新。
2. 通知公告提醒。
3. 审批状态变化。
4. 工单状态变化。
5. 项目进度反馈。
6. 库存预警。
7. 协作团队派工、执行反馈和结算审批提醒。
8. 供应商询价、竞价报价、采购订单、发货到货提醒。

### 11.2 技术方案

优先级建议：

1. AJAX 局部刷新：适用于列表、表单、仪表盘卡片。
2. 轮询：适用于部署简单的待办和通知数量更新。
3. Server-Sent Events：适用于消息提醒、审批状态推送。
4. WebSocket：适用于后续需要高频双向通信的场景。

在 HTML + PHP 原生架构下，建议一期使用 AJAX + 定时轮询，后续按需扩展 SSE。
