# 工程管理施工全流程专项设计

## 1. 设计目标

工程管理不只是工程列表和施工日志，而是围绕“施工团队 + 材料 + 现场过程 + 质量安全 + 验收交付”的闭环。

完整链路：

```text
项目/零散任务来源
  -> 工程创建
  -> 施工计划
  -> 协作团队组建
  -> 进场准备
  -> 领料/到货/签收
  -> 现场施工
  -> 施工日志
  -> 质量安全检查
  -> 隐蔽工程/阶段验收
  -> 变更签证
  -> 竣工验收
  -> 交付培训
  -> 资料归档
  -> 退料/结算/评价
```

## 2. 关键角色

| 角色 | 职责 |
| --- | --- |
| 项目负责人 | 确认工程来源、范围、预算、进度目标 |
| 工程负责人 | 负责编制施工计划、组织施工、跟踪质量安全 |
| 协作团队负责人 | 负责施工团队人员、到场、执行记录和反馈 |
| 施工人员 | 执行施工、填写日志、反馈问题 |
| 仓库管理员 | 处理领料、发货、退料、签收 |
| 质量安全员 | 进行质量检查、安全交底、隐患整改复查 |
| 验收人 | 执行阶段验收、隐蔽验收、竣工验收 |
| 财务人员 | 处理工程费用、结算和付款 |

## 3. 工程类型

| 类型 | 说明 | 来源 |
| --- | --- | --- |
| 项目工程 | 项目立项后形成的正式工程 | 项目管理 |
| 零散工程 | 临时、非完整项目的小工程 | 工程管理直接创建 |
| 运维改造工程 | 运维工单升级形成的小型工程 | 运维管理 |
| 售后工程 | 合同履约或售后服务形成的工程 | 合同/客户服务 |

## 4. 工程状态流转

| 状态 | 含义 | 进入条件 | 下一步 |
| --- | --- | --- | --- |
| draft | 草稿 | 新建工程 | 提交施工计划 |
| planning | 计划中 | 已创建工程 | 编制施工计划、团队和材料 |
| ready | 待进场 | 施工计划通过 | 团队进场 |
| mobilized | 已进场 | 完成进场确认 | 施工中 |
| constructing | 施工中 | 开始施工 | 日志、质量、安全、材料 |
| paused | 暂停 | 因材料、客户、天气、审批等原因暂停 | 恢复施工 |
| pending_acceptance | 待验收 | 施工完成 | 验收 |
| rectifying | 整改中 | 验收或检查发现问题 | 整改复查 |
| accepted | 已验收 | 验收通过 | 交付归档 |
| delivered | 已交付 | 交付培训、资料归档完成 | 结算 |
| settled | 已结算 | 费用结算完成 | 归档 |
| archived | 已归档 | 项目或工程关闭 | 结束 |
| cancelled | 已取消 | 按规则取消 | 结束 |

## 5. 施工计划

施工计划字段：

| 字段 | 说明 |
| --- | --- |
| 工程 ID | 关联工程 |
| 施工范围 | 明确边界和不包含事项 |
| 施工节点 | 节点名称、计划开始、计划结束、责任人 |
| 协作团队 | 施工团队、负责人、成员 |
| 材料需求 | 物料、规格、数量、计划到货时间 |
| 设备需求 | 施工设备、工具、车辆 |
| 风险预案 | 天气、停电、客户现场限制、安全风险 |
| 安全交底计划 | 交底时间、交底人、参与人 |
| 验收节点 | 阶段验收、隐蔽验收、竣工验收 |

## 6. 协作团队组建

工程施工团队由协作团队管理提供：

1. 工程负责人提出施工团队需求。
2. 协作团队管理按技能、资质、区域、历史评价推荐团队。
3. 选择内部团队、外部人员、外聘人员或外部公司。
4. 涉密工程需校验团队成员涉密授权。
5. 施工团队确认派工。
6. 生成工程团队清单。

团队清单字段：

| 字段 | 说明 |
| --- | --- |
| 工程 ID | 关联工程 |
| 团队 ID | 协作团队 |
| 成员 ID | 内部/外部/外聘人员 |
| 角色 | 队长、施工员、安全员、资料员 |
| 技能 | 电工、弱电、网络、土建等 |
| 进场状态 | 未进场、已进场、已退场 |
| 到场时间 | 实际到场 |
| 退场时间 | 实际退场 |

## 7. 进场管理

进场前必须完成：

1. 施工计划确认。
2. 团队派工确认。
3. 材料计划提交。
4. 安全交底。
5. 客户现场进场许可。
6. 涉密项目知悉范围确认。

进场记录字段：

| 字段 | 说明 |
| --- | --- |
| 工程 ID | 关联工程 |
| 进场日期 | 实际进场日期 |
| 进场人员 | 到场成员 |
| 现场负责人 | 客户或内部负责人 |
| 进场条件 | 水电、网络、场地、许可 |
| 进场照片 | 附件 |
| 进场确认人 | 签字/确认 |

## 8. 领料、到货与退料

### 8.1 领料流程

```text
施工计划材料需求
  -> 物料申请
  -> 库存审核
  -> 出库
  -> 现场签收
  -> 工程材料记录
```

### 8.2 采购到货流程

```text
库存不足
  -> 供应链采购询价/竞价
  -> 比价清单
  -> 采购订单审批
  -> 供应商发货
  -> 到货验收
  -> 入库或直发现场
  -> 工程签收
```

### 8.3 退料流程

```text
施工完成/材料剩余
  -> 退料申请
  -> 仓库验收
  -> 入库
  -> 工程材料结算
```

材料记录字段：

| 字段 | 说明 |
| --- | --- |
| 工程 ID | 关联工程 |
| 物料 ID | 关联物料 |
| 计划数量 | 施工计划需求 |
| 申请数量 | 领料申请数量 |
| 出库数量 | 实际出库 |
| 签收数量 | 现场签收 |
| 使用数量 | 实际使用 |
| 退料数量 | 退回仓库 |
| 损耗数量 | 损耗 |
| 来源 | 库存、采购、直发现场 |

## 9. 施工日志

施工日志必须每日填写，支持移动端或现场填报。

日志字段：

| 字段 | 说明 |
| --- | --- |
| 工程 ID | 关联工程 |
| 日期 | 日志日期 |
| 天气 | 天气情况 |
| 到场人员 | 当日人员 |
| 施工内容 | 当日完成内容 |
| 使用材料 | 当日用料 |
| 使用设备 | 当日设备 |
| 进度百分比 | 当日累计进度 |
| 现场照片 | 附件 |
| 问题与风险 | 当日问题 |
| 需协调事项 | 需客户或内部协调 |
| 明日计划 | 下一步安排 |

### 9.1 施工日志第三方查看

施工日志可能需要分享给客户、监理、审计、外部验收人员等第三方查看。第三方查看不应直接开放工程管理后台，而应通过“受控分享”实现。

#### 9.1.1 分享对象

| 分享对象 | 典型场景 | 访问方式 |
| --- | --- | --- |
| 客户现场负责人 | 查看每日施工进度 | 临时访客链接或客户联系人账号 |
| 监理单位 | 查看施工日志和质量整改 | 临时访客链接 |
| 第三方审计 | 查看工程过程证据 | 临时访客链接，限制下载 |
| 外部验收人员 | 查看验收前日志和照片 | 临时访客链接 |
| 协作团队负责人 | 查看本团队施工日志 | 外部协作账号 |

#### 9.1.2 分享范围

分享时必须选择范围：

1. 指定工程。
2. 指定日志日期范围。
3. 是否包含现场照片。
4. 是否包含材料用量。
5. 是否包含问题与整改。
6. 是否允许下载附件。
7. 是否显示施工人员姓名。
8. 是否显示涉密字段。

默认规则：

1. 默认不显示材料单价、成本、合同金额。
2. 默认不显示施工人员手机号、身份证等个人信息。
3. 默认不允许下载附件，只允许在线预览。
4. 涉密工程默认禁止公开分享，必须走涉密审批。

#### 9.1.3 分享有效期

分享链接必须设置有效期：

| 场景 | 默认有效期 |
| --- | --- |
| 客户查看施工进度 | 7 天 |
| 监理查看过程资料 | 30 天 |
| 第三方审计 | 15 天 |
| 外部验收 | 7 天 |

链接过期后自动失效。工程负责人和系统管理员可以提前撤销分享。

#### 9.1.4 分享安全要求

1. 分享链接使用随机 token，不暴露工程 ID。
2. token 存储时保存 hash，不保存明文。
3. 每次访问记录 IP、User-Agent、访问时间、访问对象。
4. 分享页面带水印，水印包含访问人、访问时间、IP。
5. 禁止搜索引擎索引，页面添加 `noindex`。
6. 涉密内容必须按密级和知悉范围校验。
7. 对超过访问频率的链接进行临时冻结。
8. 撤销分享后立即不可访问。

#### 9.1.5 第三方可见页面

第三方查看页只展示：

1. 工程名称。
2. 工程进度。
3. 施工日期。
4. 施工内容。
5. 现场照片。
6. 问题与整改摘要。
7. 下一步计划。
8. 验收相关记录。

不得展示：

1. 项目成本。
2. 合同金额。
3. 内部审批意见。
4. 员工敏感信息。
5. 未授权涉密资料。
6. 供应商报价和采购成本。

## 10. 质量安全

质量安全包含：

1. 安全交底。
2. 质量检查。
3. 安全检查。
4. 隐患整改。
5. 复查关闭。
6. 事故/特殊事件报告。

质量安全记录字段：

| 字段 | 说明 |
| --- | --- |
| 类型 | 安全交底/质量检查/安全检查/整改/事故 |
| 检查项 | 检查内容 |
| 问题等级 | 一般、严重、重大 |
| 责任人 | 负责整改 |
| 整改期限 | 截止日期 |
| 整改结果 | 整改说明 |
| 复查结果 | 通过/不通过 |
| 附件 | 照片、报告 |

## 11. 隐蔽工程与阶段验收

隐蔽工程必须在覆盖前验收。

验收类型：

| 类型 | 说明 |
| --- | --- |
| 隐蔽验收 | 管线、埋设、封闭前验收 |
| 阶段验收 | 关键节点完成后验收 |
| 竣工验收 | 工程整体完成验收 |
| 交付验收 | 客户接收和资料交付确认 |

验收字段：

| 字段 | 说明 |
| --- | --- |
| 验收类型 | hidden/stage/final/delivery |
| 验收项 | 验收检查项 |
| 验收结果 | 通过/有条件通过/不通过 |
| 验收人 | 内部/客户/第三方 |
| 问题清单 | 不通过或整改项 |
| 整改要求 | 整改内容和期限 |
| 复验记录 | 整改后复验 |
| 验收附件 | 照片、签字单、报告 |

## 12. 变更签证

触发条件：

1. 施工范围变化。
2. 工期变化。
3. 材料变化。
4. 费用变化。
5. 客户要求新增内容。
6. 现场条件变化。

变更签证流程：

```text
提出变更
  -> 填写原因、内容、费用影响、工期影响
  -> 上传现场资料
  -> 审批
  -> 审批通过后回写项目成本和合同执行
  -> 更新施工计划
```

## 13. 验收交付

验收交付必须包括：

1. 施工完成确认。
2. 材料使用和退料确认。
3. 质量安全问题关闭。
4. 变更签证处理完成。
5. 验收记录。
6. 交付资料。
7. 交付培训。
8. 客户签收。
9. 资料归档。

交付资料：

| 资料 | 是否必须 |
| --- | --- |
| 工程验收单 | 是 |
| 施工日志汇总 | 是 |
| 材料清单 | 是 |
| 变更签证单 | 有变更时必须 |
| 培训记录 | 有培训时必须 |
| 现场照片 | 是 |
| 涉密资料清单 | 涉密工程必须 |

## 14. 工程结算

结算来源：

1. 合同金额。
2. 变更签证金额。
3. 材料成本。
4. 协作团队结算。
5. 其他现场费用。

结算必须校验：

1. 工程已验收。
2. 材料已签收或退料。
3. 协作团队评价已完成。
4. 变更签证已审批。
5. 涉密资料已归档。

## 15. 与其他模块级联

| 关联模块 | 级联关系 |
| --- | --- |
| 项目管理 | 项目创建工程，工程进度回写项目 |
| 协作团队管理 | 工程派工、执行记录、评价、结算 |
| 库存管理 | 领料、出库、签收、退料 |
| 供应链采购管理 | 库存不足时发起采购、到货 |
| 合同管理 | 合同执行、变更签证、结算 |
| 财务管理 | 工程成本、协作团队付款、供应商付款 |
| 培训管理 | 交付培训、验收培训 |
| 涉密管理 | 涉密工程资料、密级和知悉范围 |
| 工作台 | 派工待办、验收待办、整改待办 |

## 16. 工程管理验收标准

1. 工程必须可从项目创建，也可创建零散工程。
2. 工程必须能选择协作团队和施工成员。
3. 工程必须支持进场记录。
4. 工程必须支持领料、签收、退料。
5. 施工日志必须能按日期记录人员、材料、进度、照片和问题。
6. 质量安全问题必须能形成整改闭环。
7. 隐蔽工程必须能单独验收。
8. 阶段验收和竣工验收必须可区分。
9. 变更签证必须进入审批并影响成本。
10. 验收通过后必须能归档资料并触发结算。
