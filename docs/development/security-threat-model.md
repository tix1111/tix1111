# 安全威胁模型

## 1. 目标

识别系统主要攻击面，明确防护措施，特别关注涉密数据、供应商账号、外部协作账号、文件上传、审批和导出等高风险点。

## 2. 资产清单

| 资产 | 风险等级 | 说明 |
| --- | --- | --- |
| 用户账号和密码 | 高 | 登录凭证 |
| 客户联系人画像 | 高 | 包含手机号、喜好、家庭情况、社会关系 |
| 合同和财务数据 | 高 | 合同金额、付款、应收、报销 |
| 涉密文件和附件 | 极高 | 按密级管理 |
| 涉密审计日志 | 极高 | 追责依据，不可篡改 |
| 供应商报价 | 高 | 竞价敏感数据 |
| 供应商账号 | 高 | 外部账号入口 |
| 外部协作账号 | 高 | 外部人员入口 |
| 施工日志分享链接 | 高 | 第三方无登录或轻量访问入口 |
| 数据库备份 | 极高 | 全量数据 |

## 3. 威胁与防护

### 3.1 登录暴力破解

风险：

1. 连续尝试密码。
2. 猜测默认账号。

防护：

1. 登录验证码。
2. 连续失败锁定。
3. 首次登录强制改密。
4. 登录日志记录 IP 和 User-Agent。
5. 高风险 IP 进入黑名单。

### 3.2 SQL 注入

风险：

1. 列表查询条件拼接 SQL。
2. 排序字段被注入。

防护：

1. 所有 SQL 使用 PDO 预处理。
2. `order_by` 必须做白名单映射。
3. 不允许直接拼接用户输入。

示例：

```php
$allowedOrder = ['created_at', 'amount', 'status'];
if (!in_array($orderBy, $allowedOrder, true)) {
    $orderBy = 'created_at';
}
```

### 3.3 XSS

风险：

1. 通知公告富文本。
2. 客户拜访内容。
3. 工单描述。

防护：

1. 输出时 HTML 转义。
2. 富文本白名单过滤。
3. 禁止 `<script>`、`onerror`、`javascript:`。
4. 上传图片通过附件服务。

### 3.4 CSRF

风险：

1. 用户登录状态下被诱导提交表单。

防护：

1. 写操作必须验证 `X-CSRF-Token`。
2. Cookie 使用 `SameSite=Strict`。
3. 后端校验来源和 token。

### 3.5 文件上传攻击

风险：

1. 上传 PHP 脚本。
2. 伪造图片 MIME。
3. 路径穿越。

防护：

1. 扩展名白名单。
2. `finfo_file` 校验 MIME。
3. 随机文件名。
4. 非 Web 目录存储。
5. 下载必须走 API。
6. 禁止执行上传目录中的脚本。

### 3.6 越权访问

风险：

1. 修改 URL 参数访问他人数据。
2. 前端隐藏菜单但 API 未校验。

防护：

1. API 层校验权限。
2. API 层校验数据范围。
3. 供应商账号强制 `supplier_id = 当前供应商`。
4. 外部协作账号强制 `team_id` 或 `assignment_id` 范围。

### 3.7 涉密数据泄露

风险：

1. 有业务权限但无密级权限。
2. 下载涉密附件未审计。
3. 外发涉密文件绕过审批。

防护：

1. RBAC 后额外校验密级。
2. 校验知悉范围。
3. 涉密下载、导出、复制、打印、外发全部记录审计。
4. 高密级下载和外发必须审批。
5. 异常访问告警。

### 3.8 供应商报价泄露

风险：

1. 供应商看到其他供应商报价。
2. 平台内部未授权人员查看比价明细。

防护：

1. 供应商账号接口强制过滤 `supplier_id`。
2. 供应商报价明细只对平台采购授权角色可见。
3. 比价清单对普通业务人员只显示推荐结果，不显示所有竞价细节。
4. 报价截止前供应商只能查看自己的报价。

### 3.9 审批绕过

风险：

1. 直接调用业务状态接口跳过审批。
2. 修改审批任务处理人。

防护：

1. 业务提交必须创建审批实例。
2. 状态变更必须校验审批结果。
3. 审批任务只能由当前处理人处理。
4. 审批流配置变更记录日志。

### 3.10 导出泄露

风险：

1. 导出包含敏感字段。
2. 大批量导出客户或财务数据。

防护：

1. 导出权限独立控制。
2. 导出字段白名单。
3. 敏感字段默认脱敏或不导出。
4. 导出行数限制。
5. 导出操作写日志。

### 3.11 施工日志分享链接泄露

风险：

1. 分享链接被转发给未授权人员。
2. 分享链接长期有效。
3. 第三方通过链接看到成本、人员隐私、涉密照片。
4. 分享链接被爬虫或搜索引擎索引。

防护：

1. 分享链接使用随机 token，数据库只保存 token hash。
2. 分享必须设置有效期，默认不超过 7 天。
3. 支持随时撤销分享。
4. 分享页面只显示白名单字段，默认脱敏施工人员和材料成本。
5. 默认禁止下载，只允许在线查看。
6. 分享页面加水印，显示访问人、时间、IP。
7. 所有访问写入 `engineering_log_share_access_logs`。
8. 涉密工程分享必须先走涉密外发/借阅审批。
9. 页面添加 `noindex`，禁止搜索引擎收录。
10. 访问频率异常时冻结分享链接。

## 4. 安全测试清单

| 测试项 | 预期 |
| --- | --- |
| 未登录访问 API | 返回 2001 |
| 无权限访问 API | 返回 3002 |
| 越权访问他人数据 | 返回 3003 |
| 低密级访问高密级 | 返回 3004 |
| 不在知悉范围访问 | 返回 3005 |
| 上传 PHP 文件 | 拒绝 |
| XSS 内容提交 | 输出时被转义或过滤 |
| CSRF 缺失 | 写操作拒绝 |
| 供应商访问他人订单 | 返回 403 |
| 大批量导出 | 受权限和数量限制 |
| 施工日志分享过期 | 过期后不可访问 |
| 施工日志分享撤销 | 撤销后不可访问 |
| 涉密工程日志分享 | 未审批不可分享 |

## 5. 安全上线检查

1. `display_errors=Off`。
2. 数据库使用最小权限账号。
3. 上传目录不可执行。
4. config/includes/sql 目录不可直接访问。
5. 登录失败锁定启用。
6. CSRF 启用。
7. 涉密审计日志开启。
8. 数据库备份加密。
9. Nginx 安全响应头启用。
10. 默认密码已修改。
