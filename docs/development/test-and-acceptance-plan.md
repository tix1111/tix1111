# 测试与验收计划

## 1. 测试目标

验证系统满足以下目标：

1. 菜单、接口、数据均受权限控制。
2. 业务模块数据来自 API，不在页面写测试数据。
3. 审批、附件、日志、消息等公共能力可复用。
4. 涉密数据不可越权访问。
5. 核心业务链路可以闭环。

## 2. 测试类型

| 类型 | 目标 |
| --- | --- |
| 单元测试 | 验证 PHP 公共函数、编号生成、权限判断 |
| 接口测试 | 验证 API 参数、响应、权限和业务规则 |
| 页面测试 | 验证列表、表单、详情、分页、搜索、按钮 |
| 权限测试 | 验证菜单、按钮、API、数据范围 |
| 涉密测试 | 验证密级、知悉范围、下载审计 |
| 集成测试 | 验证跨模块业务链路 |
| 性能测试 | 验证列表查询、报表、文件下载性能 |
| 安全测试 | 验证 SQL 注入、XSS、CSRF、文件上传 |

## 3. 基础权限测试

| 用例 | 步骤 | 预期 |
| --- | --- | --- |
| admin 菜单 | admin 登录 | 显示全部 17 个主菜单 |
| dpt1 菜单 | dpt1 登录 | 只显示授权菜单 |
| user1 菜单 | user1 登录 | 只显示普通用户菜单 |
| 越权 API | user1 直接访问系统管理 API | 返回 403 |
| 数据范围 | user1 查询非本人单据 | 返回空或 403 |
| 外部账号 | 供应商账号访问客户 API | 返回 403 |

| 用例 | 步骤 | 预期 |

## 6. 项目工程测试

| 用例 | 步骤 | 预期 |
| --- | --- | --- |
| 项目立项 | 提交项目立项 | 进入审批 |

| 验收交付 | 提交验收记录 | 工程完成并归档 |
| 工程结算 | 验收后提交结算 | 生成付款或成本归集 |

## 12. 文件安全测试

| 用例 | 步骤 | 预期 |
| --- | --- | --- |
| 上传 PHP 文件 | 上传 `.php` | 拒绝 |
| 修改扩展名 | php 改成 jpg 上传 | MIME 校验拒绝 |
| 超大文件 | 超过限制 | 返回文件过大 |
| 直接访问路径 | 访问上传真实路径 | 403 或不可访问 |
| 附件下载 | 通过 API 下载 | 有权限才成功 |

## 14. 验收交付清单

每个模块交付时必须提供：

1. 页面截图。
2. API 列表。
3. 数据库表清单。
4. 权限点清单。
5. 测试用例结果。
6. 已知问题清单。
7. 是否涉及涉密数据说明。
8. 是否涉及导出、下载、外发说明。
