# 报表统计需求规格

## 1. 报表设计原则

1. 所有报表必须从业务事件和业务表聚合，不允许手工录入报表数据。
2. 所有报表必须受数据权限控制，只展示用户可访问范围内的数据。
3. 导出功能需要独立权限点。
4. 报表数据较大时（超过 1000 行）必须分页或提供后台导出任务。
5. 实时报表 API 使用只读数据库连接（如有主从），避免影响写操作。

## 3. 主要业务报表

### 3.1 项目报表

**项目列表报表**：

| 字段 | 说明 |
| --- | --- |
| 项目名称/编号 | — |
| 客户 | — |
| 项目经理 | — |
| 部门 | — |
| 计划工期 | start_date ~ end_date |
| 实际进度 | 任务完成率% |
| 预算 | budget |
| 已用成本 | SUM(project_costs.amount) |
| 预算执行率 | 已用/预算 |
| 状态 | — |

**项目成本分析报表**：按费用类型汇总（报销/付款/物料/人工），对比预算。

**项目资源报表**：项目成员投入工时统计。

### 3.2 财务报表

**费用报销汇总**：

```
分组维度：月份 / 部门 / 人员 / 费用类别
指标：申请金额、报销金额、驳回金额、待审批金额
图表：趋势折线图、费用类别占比饼图
```

**应收账款分析**：

```
按客户/合同/逾期天数分析
到期日历（近 3 个月应收计划）
逾期金额预警
```

**供应商付款汇总**：

```
分组：供应商、月份
汇总：付款金额、待付款金额
```

### 3.3 客户销售报表

**销售漏斗报表**：

```
各阶段商机数量和金额
lead → qualify → proposal → negotiation → won
转化率、平均销售周期
```

**客户价值分析**：

```
按客户汇总成交金额、回款金额、项目数量
客户等级分布
RFM 分析（可选扩展）
```

**拜访活跃度报表**：

```
销售员本月拜访次数、拜访客户数
客户上次拜访时间（超过 30/60/90 天未拜访预警）
```

### 3.4 运维报表

**工单统计报表**：

```
分组：月份、设备类型、工单类型、处理人
指标：工单数、完成数、超时数、平均响应时长、平均处理时长
SLA 达标率
```

**设备可靠性报表**：

```
设备故障次数、MTBF（平均故障间隔）
故障原因分析
设备使用年限分布
```

**备件消耗报表**：

```
物料消耗数量、金额
按设备、部门、月份分组
```

### 3.5 工程报表

**工程进度报表**：

```
在建工程数量、计划节点 vs 实际节点
逾期工程预警（plan_end < TODAY()，status != completed）
变更签证汇总（变更数量、费用影响合计）
```

**工程成本报表**：

```
预算 vs 实际成本（报销、付款、材料）
成本偏差率
```

**验收率报表**：

```
本月验收工程数量、一次通过率、返工率
```

### 3.6 库存报表

**库存现状报表**：

```
仓库库存明细（物料、数量、金额）
低库存物料列表（qty < min_stock）
库龄分析（入库时间分组：0-30天/31-90天/91-180天/180天以上）
```

**库存流水报表**：

```
按月份、仓库、来源类型汇总出入库量
周转率 = 月出库量 / ((期初+期末)/2)
```

### 3.7 人事报表

**考勤汇总报表**：

```
分组：月份、部门
指标：出勤天数、请假天数（各类型）、加班天数、异常打卡次数
```

**薪酬报表**：

```
月薪汇总（部门、月份）
社保公积金汇总
个税汇总
```

### 3.8 培训报表

**培训完成情况报表**：

```
部门/员工维度
课程完成率、考试通过率
逾期未完成名单
```

**证书统计报表**：

```
证书类型、持证人数、即将到期证书（90天内）
```

### 3.9 党建报表

**党员统计**：

```
党员人数（按组织、部门）
党员发展情况（各阶段人数）
```

**组织生活统计**：

```
三会一课次数、出勤率
主题党日活动次数
```

**党费统计**：

```
应缴金额、实缴金额、欠缴金额
欠缴人员名单
```

### 3.10 协作团队报表

**团队评价汇总**：

```
团队质量分、时效分、安全分平均值
按团队排名
```

**派工统计**：

```
团队派工次数、工时合计、结算金额
按来源模块分组
```

### 3.11 供应链采购报表

**采购金额汇总**：

```
按供应商、物料类别、月份分组
采购数量、金额
```

**供应商履约报表**：

```
准时率、合格率、价格偏差
综合评分排名
```

**询价/竞价效率**：

```
询价单数量、参与报价供应商数、最低价节省比例
```

## 4. 报表 API 设计

所有报表接口统一放在 `/api/reports/` 下：

| 接口 | 说明 |
| --- | --- |
| `/api/reports/dashboard.php` | 看板指标 |
| `/api/reports/projects/summary.php` | 项目汇总 |
| `/api/reports/projects/cost.php` | 项目成本 |
| `/api/reports/finance/reimbursement.php` | 报销汇总 |
| `/api/reports/finance/receivable.php` | 应收分析 |
| `/api/reports/customers/funnel.php` | 销售漏斗 |
| `/api/reports/customers/value.php` | 客户价值 |
| `/api/reports/ops/workorders.php` | 工单统计 |
| `/api/reports/ops/devices.php` | 设备可靠性 |
| `/api/reports/engineering/progress.php` | 工程进度 |
| `/api/reports/inventory/stock.php` | 库存现状 |
| `/api/reports/inventory/turnover.php` | 库存周转 |
| `/api/reports/hr/attendance.php` | 考勤汇总 |
| `/api/reports/hr/salary.php` | 薪酬汇总 |
| `/api/reports/training/completion.php` | 培训完成 |
| `/api/reports/party/members.php` | 党员统计 |
| `/api/reports/party/dues.php` | 党费统计 |
| `/api/reports/collaboration/summary.php` | 团队汇总 |
| `/api/reports/procurement/summary.php` | 采购汇总 |

所有报表接口支持：

1. 时间范围筛选（`date_from`/`date_to`）。
2. 部门筛选（受数据范围约束）。
3. 分页或 `limit` 参数。
4. `export=1` 参数触发导出（需权限）。
