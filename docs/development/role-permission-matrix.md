# 角色权限矩阵

## 1. 说明

本文档用于定义系统管理员、部门管理员、普通用户、供应商账号、外部协作账号在 17 个主菜单中的默认权限边界。

权限等级：

| 标记 | 含义 |
| --- | --- |
| A | 全部权限：查看、新增、编辑、删除、审批、导出、配置 |
| M | 管理权限：查看、新增、编辑、审批、导出，不含全局配置和删除 |
| E | 执行权限：查看、处理本人/本团队任务、提交反馈 |
| V | 查看权限：只读或本人数据 |
| - | 默认无权限 |

## 4. 普通用户默认可见范围

普通用户默认只看：

1. 本人发起的单据。
2. 本人审批相关单据。
3. 本人参与的项目、工程、工单。
4. 本人被授权的涉密对象。
5. 本人党员档案和党建学习记录。
6. 本人培训记录和证书。

## 5. 供应商账号权限

供应商账号只允许：

1. 查看和维护本供应商资料。
2. 上传和维护本供应商商品。
3. 查看平台发给本供应商的询价/竞价。
4. 提交本供应商报价。
5. 查看本供应商采购订单。
6. 提交发货、到货反馈。
7. 查看本供应商履约评价。

供应商账号禁止：

1. 查看其他供应商报价。
2. 查看比价规则明细中其他供应商名称和价格。
3. 查看平台内部审批意见。
4. 查看客户、项目、财务、涉密资料。

## 6. 外部协作账号权限

外部协作账号只允许：

1. 查看本人或本团队派工任务。
2. 提交执行记录、照片、问题反馈。
3. 查看本人任务评价结果。
4. 查看与本人任务相关的有限资料。

外部协作账号禁止：

1. 查看完整项目成本。
2. 查看客户敏感信息。
3. 查看合同金额和付款信息。
4. 查看未授权涉密资料。

## 7. 权限实施要求

1. 前端隐藏按钮不是权限控制，API 必须再次校验。
2. 导出、下载、删除、授权、恢复等高危操作必须记录日志。
3. 涉密对象权限必须在 RBAC 之后额外校验密级和知悉范围。
4. 外部账号默认不能访问内部组织架构和员工档案。
